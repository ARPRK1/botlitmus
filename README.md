# BotLitmus

Public honesty scores for Indian help centres and customer-facing support.

**Does this help centre tell the truth?**

This is not a chatbot builder. It is a public record of whether the refund clock, the phone number, and the homepage slogan agree.

## Live

Not deployed on first commit. After Vercel: update `docs/STATE.md`.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run scan -- https://support.zerodha.com/
```
